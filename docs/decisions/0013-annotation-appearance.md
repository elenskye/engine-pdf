# 0013 标注的外观与读回

2026-11-26。Phase 3 的既有标注接口按站主裁定返回可用于重建的数据，文本框使用标准 PDF 标注外观（ASK）。

- `Document::annotations(page)` 交出位置、内容、作者和种类。能解析的标注另带 `Annotation::mark`。图章从已有外观绘成带透明通道的 PNG。读取顺序跳过表单控件和弹窗，弹窗随所属标注删除。
- PDFKit 在同样几何的空白页上画出标准标注与外观流，再搬到输出页（`0017`）。文本框含中日文时用苹方、否则用 Helvetica，不自动换行，放不下就整体缩小（PDF.js 按自己的字宽定框）。自由文本用矢量外观保留指定文字透明度和边框颜色，显示文字存在 `/Contents`，独立批注文字存在 `/Subj`。图章接受 PNG 和 JPEG。省略作者时清除 PDFKit 默认写入的系统帐户名。
- 引擎保存可选的颜色数组，补充 PDFKit 读回丢失的透明度和边框颜色。其他阅读器按标准外观显示，外部标注按已有属性尽量恢复。应用在同一份原始 PDF 上使用读取到的 `MarkId`。
