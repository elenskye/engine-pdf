# 0012 编辑时保留原页内容流

> 已被 `0017` 取代：改动改由 lopdf 在原文件的对象上写，内容流不经 PDFKit 重写，不再需要核对和恢复。

2026-11-25。站主同意在 v0.5.0 Phase 2 增加保留原页内容与字体资源的写入路径（ASK）。

- macOS 27.2.1 的 PDFKit 在重建中文样本时去掉原内容流的 `/ActualText`。`/ToUnicode` 保持一致，页面光栅图也保持一致，复制或搜索得到的文字仍会变化。CoreGraphics 重画也出现同样结果。
- `edit::apply` 由 PDFKit 生成页序、旋转、标注、目录和文件信息，重开后逐页核对文字层。只有检测到文字变化才启用 `lopdf`，其默认特性关闭，仍走同步接口。
- 从所选原页恢复未改写的 `/Contents`、继承的 `/Resources`、透明组和 `/UserUnit`，重映射绘制资源引用，保留输出页对象以及其中的链接和目录引用。PDFKit 会归零非零的页面原点，恢复内容流时按两者的差值平移。内容恢复后再次逐页核对，仍有差异时报 `Error::EditTextChanged` 和输出页码。
