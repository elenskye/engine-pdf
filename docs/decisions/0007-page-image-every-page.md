# 0007 逐页读取默认每页都给页图

> 2026-11-27：Peck 1.1.12 起按模型窗口定一次附几张（每 5 万 token 一张），站主定接引擎时保留；`pdf_read` 为此加了 `max_images`。

2026-11-25 站主定。

- `ReadOptions` 默认每页附一张 1568px 的 JPEG，空白页和读失败的页除外；有文字层的页也给。看不看由模型决定，和 Claude Code 读 PDF 的做法一致（每页文字 + 页图）。
- 原因：准确性优先。页上的图表、照片、公式、复杂表格，文字层表达不了或是乱码；原来只给「没取到字」的页出图，模型看不到这些。
- 代价：每页多几十毫秒画图；给模型时一张图约 1,500 tokens。不给模型看的场景（建索引、存库、知识库分段）由 App 设 `render: None`。
- 去掉 `Render::only_no_text()`；`Render::at_most(n)` 留着，默认不限。
- Peck（v0.4.0）：能看图的模型每页都附图，去掉原来一次最多 6 张的上限；不能看图的模型只给文字。Pith、Pomelo 接入时给模型看的地方照这个默认。
