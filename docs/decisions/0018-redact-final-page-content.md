# 0018 按最终页面涂黑并验证输出

2026-11-26 站主定（ASK）；2026-11-27 审核时按 `0019` 改了写法。

- 先做页面对象、结构、标注、表单和烧平等编辑，再在最终页上涂黑。涂黑框引用主文档的原始物理页和 PDF 坐标，同一原始页的每个输出副本都涂。
- **先在原内容流上涂**：删掉整个落在框里的字、图片和路径；只沾到框、没有字形落进框的字，和两端都在框外的线条（表格线、底色块）不动；能安全改像素的普通图片把框内像素抹黑另存一张。最后在页面最上层盖黑框。
- **整页位图后备**：有字形压在框边、框碰到 Form、斜放或带透明的图片、或页面别处跟着变了时，这一页画成图再抹黑，用 Vision 补回框外的搜索层（跨过框的行按字切开，只留框外的字）。
- 共享图像可能让别处留着框里的原像素：原图仍有引用、或几个副本遮的范围不同时返回 `RedactionSharedImage`，调用方调整范围或页序后重试。
- 保存前验证：PDFium 的字形框和 PDFKit 的字框中心都不在框里，页图框内全黑，旧内容流、缩略图、`PieceInfo`、OCR 文本和原图都已不在文件里；带结构树的页去掉替代文字（`0019`）。验证不过返回错误。框里有没烧平的表单控件返回 `RedactionFailed`。
- 涂黑的作用范围是页面内容。文件信息、书签、附件可能另存了同一段内容，App 在确认时说明。
