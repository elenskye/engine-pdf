# 0014 AcroForm 填值与烧平

2026-11-26。站主确认逻辑字段附多个控件位置，以及原页序下保留活表单、调整页面前先烧平（ASK）。

- `Document::fields(&Cancel)` 按全限定名称返回逻辑字段。`Plan.fill` 指向主文件的字段。`lopdf` 写入字段 `/V`、按钮的 `/AS` 和原有外观状态，PDFKit 绘制文本和选项的矢量外观。填值和绘制过程只读取字段数据，表单动作保持未执行。
- 仅填值使用原有页面结构。页序和旋转都不变时，表单和控件留在原文件里，与新标注、目录和文件信息一起保存（`0017`）。改变页面排列或旋转时，用 `Save.flatten` 先把控件画入来源页面再拼页。`/Fields` 为空的 `/AcroForm`（很多论文带着）不算表单。
- PDFKit 直接烧平会改变 `/ActualText` 并移除超链接。引擎将 PDFKit 画出的标注与控件外观作为矢量层追加到原内容流，移除相应的可编辑对象。导航链接保留可点。XFA 报 `Error::UnsupportedForm`。
