# engine-pdf · 第二轮简报：新开发计划

> 2026-11-25 站主在对话里给的原话（原件，不改）。据此拟的计划见 `ROADMAP.md` v0.5.0–v0.8.0，选型见 `decisions/0008`–`0011`。

我认为目前 engine-pdf 的能力仍有欠缺，并非完全体，无法满足三家 App 的需求，我的整体优化建议如下：

1. 第一步是，借助 PDFKit 结合 PDF.js 达到 macOS Preview 的水准：
   1. 基本编辑（高亮、批注、绘图、文本框、图片签名）
   2. 页面管理（合并、插入、删除、旋转、重排）
   3. 表单填写与密码设置
2. 第二步是，引入 PDFium：
   1. 补齐可搜索扫描件
   2. 移动与删除文本/图片
   3. 基础密文涂黑功能
3. 额外补充：读取目录/书签，Pith 页面标签（page labels）是否与阅读器一致待验证，把照片打包成 PDF，把导出的文章拼成带链接、目录和标题的 PDF
4. 额外补充后两项设计 Pomelo 的引擎调用，我上传了一个 Brief，也要作为整体开发的一部分（`docs/brief-pomelo.md`）
5. 这一步你只拟定开发计划，尽量使用 ASK 功能询问我决策点，如果决策点实在非常多，你再考虑使用云端问卷的方式（不同步到 Atelier）
